We are happy to announce that we have just released `Cordova Node Xcode 4.0.0`!

This is one of the libraries used behind-the-scenes for parsing, editing, and writing xcodeproj project files.

* [cordova-node-xcode@4.0.0](https://www.npmjs.com/package/xcode)

## Release Highlights

In this major release, the `uuid` dependency has been replaced with Node.js's built-in `crypto.randomUUID()` API. As a result, the minimum Node.js engine requirement has been bumped to `>=14.17.0`.

Support for the `PBXShellScriptBuildPhase` options `alwaysOutOfDate` and `runOnlyForDeploymentPostprocessing` has been added.

Additionally, the following fixes were applied:

- Shallow-merging of section properties while preserving previously parsed entries that have the same section name.
- Allow adding a `PBXBuildFile` entry with the `name` property defined when `path` is not defined.
- Pathing issues on Windows.
- Ensure that the `PBXGroup` object exists before attempting to read the `path` property.

Please report any issues you find to the [Cordova Node Xcode Issue Tracker](https://github.com/apache/cordova-node-xcode/issues)!
